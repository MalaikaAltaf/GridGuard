Grid-Guard AI — Visual System

One design system, two surfaces. Skeuomorphic control-room language — brushed enclosure panels, engraved plates, LED status lamps, analog gauges — grounded in the world the two users actually work in: substations, meters, case files. Applied with restraint so the Risk Queue stays legible at thousands of rows.

Risk colors never carry meaning alone — see the badge component below. Copper is reserved for primary officer actions (Assign Case, Sign In). Steel is reserved for system-generated events, never for risk.

Signature component — the risk badge

Appears identically on the officer's dashboard and the inspector's phone: a chrome-bezel LED lamp (color) + a distinct icon shape (never shared between bands) + the word itself. This is how the officer and inspector confirm they're looking at the same case.

HighScore 80–100

Buttons & inputs

Copper buttons are embossed and depress on click (translateY + inset shadow) — reserved for the one primary action per screen. Everything else stays a flatter outline button so the primary action doesn't get lost.

Component states

One state system, reused on every screen: loading, two distinct empty states, error-with-retry. (Mobile adds an offline/pending-sync state — see the mobile spec.)
